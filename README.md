# CheckSimila

Windows desktop application for **plagiarism detection** and
**AI-generated text detection** in documents.

- Formats: PDF, Word, PowerPoint, Excel, Visio, HTML, text
- Plagiarism detection: searches the web for sources and compares them side by side
- AI detection: local analysis, English texts (no data sent to any external service)
- Choose what to install: plagiarism + AI, plagiarism only, or AI only
- Per-computer activation (one key per computer)

## Installation

Download `CheckSimila-2.1.13-setup.exe` from the
[Releases](../../releases) section and run it. Java is not required (included).
