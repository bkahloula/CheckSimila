# CheckSimila

Application de bureau Windows pour la **détection de plagiat** et la
**détection de texte généré par IA** dans les documents.

- Formats : PDF, Word, PowerPoint, Excel, Visio, HTML, texte
- Détection de plagiat : recherche des sources sur le web et comparaison côte à côte
- Détection IA : analyse locale, textes en anglais (aucune donnée envoyée à un service externe)
- Installation au choix : plagiat + IA, plagiat seul, ou IA seul
- Activation par poste (une clé par ordinateur)

## Installation

Télécharger `CheckSimila-2.1.13-setup.exe` dans la section
[Releases](../../releases) et l'exécuter. Java n'est pas nécessaire (inclus).
